# AI Agent Task Planner

A small Python project that demonstrates the basic idea behind an AI agent: take a user goal, decide which tools are useful, run those tools, and return a simple plan.

This project does not try to be a full agent framework. It is intentionally small so the flow is easy to understand and explain.

## Tools Included

- calculator
- note search
- checklist planner

## Why This Project

Many AI engineering roles now mention agents, tool use, and workflow automation. This project shows the concept without hiding the logic inside a large framework.

## Run

```bash
python main.py --goal "Plan a small RAG project and estimate 3 days of work at 4 hours per day"
```
